# Tasty Coffee — учебный проект ЭПИ

## Описание

Лабораторная работа №2 по дисциплине «Экономика программной инженерии», посвящённая планированию и управлению разработкой Tasty Coffee.

## Работа с задачами

Каждый коммит, связанные с задачей, должны содержать её идентификатор YouTrack, например `TCEPI-1`.
